How to use this playbook

  1. One prompt per message. Copy the dark box exactly. Don't combine parts.
  2. Claude plans first. It lists the slides it will add. Reply "go" or correct it.
  3. Check it in the browser. Open the link Claude gives you and go through the "Done when" list.
  4. Commit. Ask "commit this part". One commit per part.

Rules for every slide

  • Same style as style-sample.html. MADD colours, Inter, light background, 1920×1080, keyboard and click navigation.
  • The UI is the main thing. Real screens from design/app-screens/, numbered markers on the phone, matching explanations beside it.
  • One point per slide. The title is a full sentence that states that point.
  • Only true numbers. From the IR, PLAN.md, docs/F1/ or the code. Nothing invented. If a number is missing, ask.
  • Not AI-looking. No emoji, no stock icons, no gradients for decoration, no filler words ("seamless", "robust", "cutting-edge"). Short plain sentences.
  • Speaker notes for every slide, in simple English, shown with the N key.
  • One file per part in docs/presentation/parts/, joined into deck.html. Keep each file short.

Your story (draft for you to edit)

This goes on slide 2. Claude wrote it from what you said: you are from Yemen, security matters a lot to you, and you wanted to add this feature to make safe payments easier. Change anything that isn't true for you before P1. Don't add events that didn't happen; examiners often ask about this slide.

Slide title: "I'm from Yemen, where trust in money is hard-won."

On the slide (short): From Yemen to Malaysia · Paying became one tap · One tap is also all a thief needs · So I built a wallet that keeps checking.

What you say: "I'm from Yemen. Back home, I learned early that keeping money safe is something you think about every day. When I came to Malaysia to study, e-wallets made paying and sending money very easy, just one tap. But I noticed that the same one tap is all a thief needs once they get into your phone. Security has always been very important to me, so I asked myself: what if the wallet kept checking after login, and asked me before anything unusual went through? I wanted to add that one feature, and keep paying just as easy as before. That is MADD."

Why "MADD" (مدّ): the madda is the Arabic mark that extends a sound. MADD extends protection beyond the moment you log in.
